# 📸 Fotogramm

Fotogramm is a photo-sharing application developed as part of a further education program.  
The goal of this project is to gradually transform a simple photo gallery into a social network for sharing images and interacting with other users.

---

## 🚀 Features (current / planned)

- 📷 Photo gallery
- 👤 User profiles (planned)
- 📱 Responsive design
- ⚡ Interactive UI with JavaScript

---

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
